# **Проект_1 «Удовлетворённость сотрудников»**

## **Цель:**  
Прогнозирование уровня удовлетворённости сотрудников и вероятности их увольнения на основе HR-данных.

## **Подход:**  
— Построены две ML-модели:  
  1. **Регрессия** (предсказание удовлетворённости) — лучшая модель: дерево решений (SMAPE = 14.21).  
  2. **Классификация** (предсказание увольнения) — лучшая модель: случайный лес (ROC-AUC = 0.9187).  
— Использованы стандартные этапы ML-процесса: анализ данных, предобработка, кодирование, масштабирование, подбор гиперпараметров.  
— Прогноз удовлетворённости из первой задачи использован как признак во второй.

## **Результаты:**  
— Обе модели достигли целевых метрик качества.  
— Выявлены ключевые факторы оттока: низкая удовлетворённость, зарплата, загруженность, длительность работы, оценки руководства.

## **Бизнес-ценность:**  
— Возможность раннего выявления сотрудников с высоким риском увольнения.  
— Основа для превентивных HR-мер: повышение лояльности, удержание ключевых кадров.  
— Рекомендации по внедрению моделей в HR-системы и расширению данных для дальнейшего улучшения.

# **Проект_2 «Прогноз температуры стали»**

## **Цель:**  
Прогноз конечной температуры плавки стали для оптимизации энергозатрат на производстве.

## **Подход:**  
— Обучены и сравнены модели: линейная регрессия, случайный лес, XGBoost.  
— Лучшей признана модель **XGBoost** (final_model_gb) по метрике **MAE**.  
— Выполнен анализ ключевых технологических параметров: объёмы добавок (Bulk_sum, Wire_sum), временные интервалы (Bulk_before, Bulk_after), энергетические показатели.

## **Результаты:**  
— Модель точно предсказывает конечную температуру, что позволяет избежать перегрева и избыточного энергопотребления.  
— Выявлены ключевые факторы роста затрат: избыточные добавки, неоптимальные временные интервалы, высокое потребление проволоки, неэффективный температурный режим.

## **Рекомендации:**  
— Внедрить модель XGBoost в систему управления плавкой для оперативного прогноза температуры.  
— Оптимизировать дозировку и время внесения добавок и проволоки.  
— Сократить время нагрева и общую длительность плавки без ущерба для качества.  
— Автоматизировать контроль параметров и провести анализ аномальных партий (№322, 1689, 2110).  
— Обучить персонал соблюдению энергоэффективных режимов.

## **Бизнес-эффект:**  
Снижение энергозатрат, повышение стабильности процесса и уменьшение рисков брака за счёт точного прогнозирования и управления температурой плавки.

# **Проект_3 «Аренда самокатов»**

## **Цель:**  
Проверка гипотез о поведении пользователей, эффективности подписки и маркетинговых активностей сервиса GoFast на основе данных о поездках.

## **Проверенные гипотезы и методы:**  
1. **Время поездки** — пользователи с подпиской ездят дольше (двухвыборочный t-тест).  
2. **Расстояние поездки** — среднее расстояние подписчиков превышает 3130 м (одновыборочный t-тест).  
3. **Выручка** — месячная выручка с подписчиков выше, чем с обычных пользователей (двухвыборочный t-тест по агрегированным данным).  
4. **Обращения в поддержку** — после обновления серверов их количество снизилось (парный t-тест).  
5. **Промокоды** — рассчитано минимальное число рассылок, при котором вероятность продления менее чем 100 подписок ≈ 5% (биномиальное распределение).  
6. **Push-уведомления** — оценена вероятность открытия ≤399,5 тыс. из 1 млн уведомлений при p=0.4 (нормальная аппроксимация биномиального распределения).

## **Ключевые выводы:**  
— Подписка стимулирует более длительные и, вероятно, более частые поездки.  
— Подписчики приносят больше выручки в расчёте на пользователя.  
— Техническое обновление улучшило стабильность сервиса (снижение обращений в поддержку).  
— Рассчитаны точные параметры для маркетинговых кампаний: объёмы рассылок и ожидаемые конверсии.

## **Бизнес-рекомендации:**  
— Активнее продвигать подписку Ultra как выгодный и вовлекающий продукт.  
— Использовать полученные статистические оценки для планирования маркетинговых бюджетов и оценки ROI.  
— Продолжать инвестиции в техническую стабильность — это снижает издержки на поддержку и повышает удовлетворённость.

# **Проект_4 «Продажи игр»**

## **Цель:** 

Выявить ключевые факторы успеха компьютерных игр (платформа, жанр, оценки, возрастной рейтинг ESRB) для выбора перспективных релизов и планирования рекламы.

## **Подход:**  
— Предобработка и анализ исторических данных о продажах.  
— Исследование продаж по платформам, жанрам, регионам и рейтингам ESRB.  
— Оценка влияния отзывов критиков и пользователей на объёмы продаж.  
— Сравнение пользовательских рейтингов между платформами (статистические гипотезы).

## **Результат:**  
Определены паттерны, характерные для хитов: доминирующие платформы (например, PS, Xbox), популярные жанры (Action, Shooter), высокие оценки критиков как сильный предиктор продаж, различия в предпочтениях по регионам и возрастным категориям.

## **Вывод:**  
Анализ позволяет фокусироваться на продуктах с высоким потенциалом и адаптировать маркетинг под целевые аудитории.

# **Проект_5 «Молочная ферма»**

## **Цель:** 

Прогнозировать годовой удой и вероятность получения «вкусного» молока для отбора коров с высоким продуктивным потенциалом.

## **Подход:**  
— Предобработка и анализ данных о коровах (включая генетику, кормление, физиологию).  
— Построение двух моделей:  
  1. **Линейная регрессия** — для прогноза удоя (цель: ≥6000 кг при +5% корма).  
  2. **Логистическая регрессия** — для оценки вероятности «вкусного» молока по критериям фермера.  

## **Результат:**  
Модели позволяют объективно ранжировать животных и отбирать только тех, кто удовлетворяет обоим критериям.

## **Вывод:**  
Фермер может минимизировать риски при закупке поголовья и уверенно выполнять производственный план.
Необходимо создать две прогнозные модели для отбора бурёнок в поголовье:

Прогнозирование возможного удоя коровы (целевой признак — Удой).
Расчет вероятности получить вкусное молоко от коровы (целевой признак — Вкус молока).
С помощью модели нужно отобрать коров по двум критериям: средний удой за год, при увеличении количественных показателей корма на 5%, — не менее 6000 килограммов; а молоко должно быть вкусным.
